# Ретроспектива — Underline

Файл читается целиком в начале каждого прогона. Поэтому он держится коротким:
постоянных инструкций не больше десяти, каждая существует, пока верна причина,
по которой её записали.

## Постоянные инструкции

1. **Версию зависимости берут из вывода команды, а не из головы.** Прежде чем
   вписать версию в `Cargo.toml` или `package.json`, прочитай то, что вернули
   `npm view <pkg> version` или `cargo search <crate>`. Проверка — установка
   проходит с первого раза.
2. **Версию действия GitHub Actions проверяют перед пушем.** `gh api
   repos/<owner>/<repo>/releases/latest --jq .tag_name`. Красный CI из-за
   несуществующего тега действия — самая дешёвая ошибка и самая обидная.
3. **Гейт, который нельзя прогнать локально, не добавляют в CI.** Если
   инструмента нет на машине, задача уходит на доску, а не в воркфлоу.
4. **Тест, не виденный красным, не считается доказательством.** Инвариант,
   ради которого написан тест, подсаживают дефектом и смотрят на падение.
5. **Выбор технологии — запись `DEC-####`, а не строка в манифесте.**

## Записи о расхождениях

### 2026-09-14 — версия `@types/node` вписана раньше, чем прочитана

- **Симптом:** `npm error notarget No matching version found for @types/node@26.2.1`.
  Актуальная версия — 26.5.1, и она была напечатана той же командой строкой выше.
- **Всплыло:** на стадии сборки каркаса Chat.
- **Владеет стадией:** та же — ошибка в том, что значение записали в манифест
  в том же действии, где его запрашивали, не дождавшись вывода.
- **Корень:** число подставлено по памяти о типичной нумерации, а не по факту.
- **Исправление:** значение вписано из вывода; установка прошла.
- **Что ловит в следующий раз:** постоянная инструкция 1.
