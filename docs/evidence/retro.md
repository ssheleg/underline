# Ретроспектива — Underline

Файл читается целиком в начале каждого прогона. Поэтому он держится коротким:
постоянных инструкций не больше десяти, каждая существует, пока верна причина,
по которой её записали.

## Постоянные инструкции

1. **Версию зависимости берут из вывода команды, а не из головы.** Прежде чем
   вписать версию в `Cargo.toml` или `package.json`, прочитай то, что вернули
   `npm view <pkg> version` или `cargo search <crate>`. Проверка — установка
   проходит с первого раза.
2. **Версию действия GitHub Actions проверяют перед пушем.** `gh api
   repos/<owner>/<repo>/releases/latest --jq .tag_name`. Красный CI из-за
   несуществующего тега действия — самая дешёвая ошибка и самая обидная.
3. **Гейт, который нельзя прогнать локально, не добавляют в CI.** Если
   инструмента нет на машине, задача уходит на доску, а не в воркфлоу.
4. **Тест, не виденный красным, не считается доказательством.** Инвариант,
   ради которого написан тест, подсаживают дефектом и смотрят на падение.
5. **Выбор технологии — запись `DEC-####`, а не строка в манифесте.**
6. **Предложение, написанное в этой же сессии, идёт в реестр только после
   слепого прочтения.** Автор не видит дыр в собственных правилах: слепой
   рецензент нашёл в DEC-0006…0017 пять блокеров, которых не нашёл автор при
   собственном аудите. Проверка — у каждого `Proposed` есть ссылка на рецензию.
7. **После `cargo fmt` файл переписывают целиком, а не правят дословными
   заменами.** Форматирование меняет разбиение строк, замена по точной подстроке
   молча не совпадает, и скрипт падает на первой проверке, не записав ничего.

## Записи о расхождениях

### 2026-09-14 — версия `@types/node` вписана раньше, чем прочитана

- **Симптом:** `npm error notarget No matching version found for @types/node@26.2.1`.
  Актуальная версия — 26.5.1, и она была напечатана той же командой строкой выше.
- **Всплыло:** на стадии сборки каркаса Chat.
- **Владеет стадией:** та же — ошибка в том, что значение записали в манифест
  в том же действии, где его запрашивали, не дождавшись вывода.
- **Корень:** число подставлено по памяти о типичной нумерации, а не по факту.
- **Исправление:** значение вписано из вывода; установка прошла.
- **Что ловит в следующий раз:** постоянная инструкция 1.

### 2026-09-14 — собственные предложения содержали блокеры, найденные только слепым прочтением

- **Симптом:** в DEC-0006…0017 «первый по порядку журнала» опирался на полный
  порядок, которого у причинного DAG нет; ротация коммиттера выбирала число, а не
  leaf; `space_id` определялся через событие, подписанное над `space_id`; в домене
  подписи не было поколения группы; версии протокола не было вовсе.
- **Всплыло:** на аудите, при слепом прочтении рецензентом.
- **Владеет стадией:** та, что вносила предложения в реестр — они попали туда без
  независимого прочтения.
- **Корень:** автор проверял свои правила теми же глазами, которыми писал.
- **Исправление:** DEC-0018…0025 приняты после сверки двух независимых списков.
- **Что ловит в следующий раз:** постоянная инструкция 6.

### 2026-09-14 — правки по дословной подстроке после `cargo fmt` не совпали дважды

- **Симптом:** два скрипта правок упали на `AssertionError`, не записав ничего;
  второй — после того как первый уже показал причину.
- **Корень:** `cargo fmt` изменил разбиение строк в `node.rs`, `cli.rs` и тестах;
  замены искали вчерашнее разбиение.
- **Исправление:** файлы переписаны целиком; тесты и clippy зелёные.
- **Что ловит в следующий раз:** постоянная инструкция 7.
